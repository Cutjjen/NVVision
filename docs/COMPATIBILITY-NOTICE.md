# Compatibility guidance in the settings footer

The same advisory text is registered for all maintained targets. The footer shows three short lines; the existing information button exposes the complete guidance. Brazilian Portuguese and English follow the selected UI language.

If FPS drops or a conflict occurs, users can test disabling Persistent Mapping where that option exists and advanced integration options in Sodium, Embeddium or other installed optimizers, one at a time. Compare the same scene and restore choices that do not help. The notice does not prescribe disabling every optimizer feature or removing required dependencies.

This is troubleshooting guidance, not a verified universal cause of FPS loss. The notice never edits another mod's configuration. The renderer and optimization policies remain unchanged. Shared menu geometry reserves additional footer space; existing layout and localization regressions cover the change.

The user attributed the earlier NeoForge 1.21.1 visual issue to All the Mods 10 and requested retaining the renderer as it is. No further rendering intervention is included in this update.
