# Publication identification — Cutjjen

## Category and description

Suggested category: **Optimization**. NVVision is a client-side graphics configuration mod; NVVision Addon provides CPU-related visual controls. Declare each supported loader/game combination explicitly.

NVVision brings graphics presets, spatial upscaling, dynamic-resolution controls and visual-quality settings together in one menu. Hardware-oriented themes and simple tooltips help players choose settings for their system. Integrations detect installed rendering/shader backends and apply compatibility restrictions.

Open settings with **F8** or Minecraft's **Options** screen. Choose a preset, review individual controls and apply settings. Brazilian Portuguese and English are available from language buttons. Higher quality can increase GPU, CPU or memory cost; compare changes in the same scene.

The companion addon provides CPU presets and individual native-particle/entity-distance controls. Settings apply locally and preserve player choices. Other players do not need either component installed; server simulation is unaffected. Startup-only integrations may require a restart, as explained by their controls.

Performance varies with hardware and modpack. Created by **Cutjjen**, without official Minecraft or GPU-vendor affiliation.
