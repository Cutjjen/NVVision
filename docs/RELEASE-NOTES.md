# Texto sugerido para Release

NVVision — criação de Cutjjen. Pacote de otimização visual e controles locais de CPU, com fontes compartilhadas e adaptadores para Forge, Fabric e NeoForge.

Baixe os dois JARs correspondentes ao seu Minecraft e loader. Preserve as configurações e substitua a build anterior do mesmo mod, evitando duplicatas. Instale as dependências Sodium/Iris ou Embeddium/Oculus apropriadas àquela linha.

A interface oferece português brasileiro/inglês, descrições dos controles e acesso via F8/Opções. A NeoForge 1.21.1 contém a correção r2 de integração com o menu do modpack, validada pelo usuário. As demais atualizações de adapter passaram nos testes automatizados e mantêm seu estado de validação registrado.

DLSS, geração de quadros e tradução automática OpenGL→Vulkan não fazem parte dos recursos funcionais. O funcionamento cliente não exige que todos os jogadores instalem o mod/addon. Consulte a matriz e o SHA-256 anexados.
