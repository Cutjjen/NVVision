# Mods e builds

Use esta pasta para armazenar os arquivos prontos de distribuição.

## Formato sugerido

- `nvvision-v<versao>-<loader>-<mcversion>.jar`
- `nvvision-addon-v<versao>-<loader>-<mcversion>.jar`

## Exemplos

- `nvvision-v1.1.0-forge-1.20.1.jar`
- `nvvision-addon-v1.1.0-fabric-1.21.1.jar`

## Dicas

- mantenha um arquivo por build
- não misturar versões antigas com novas
- registrar a compatibilidade em `updates/releases/`
